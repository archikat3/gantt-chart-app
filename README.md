Οδηγίες εγκατάστασης και εκτέλεσης της εφαρμογής gantt.pyw 

Ακολουθεί ένας πλήρης, βήμα προς βήμα οδηγός για την εγκατάσταση και την εκτέλεση της εφαρμογής Διαγράμματος Gantt στον υπολογιστή σας, συμπεριλαμβανομένης της εγκατάστασης της Python και όλων των απαραίτητων βιβλιοθηκών.

Βήμα 1: Εγκατάσταση της Python

1.	Μεταβείτε στον επίσημο ιστότοπο της Python: python.org.   
2.	Κατεβάστε την πιο πρόσφατη έκδοση της Python (προτείνεται η Python 3.10 ή νεότερη).
3.	Πολύ Σημαντικό (για Windows): Κατά την εκτέλεση του προγράμματος εγκατάστασης, βεβαιωθείτε ότι έχετε τσεκάρει την επιλογή "Add Python to PATH" (Προσθήκη της Python στις μεταβλητές περιβάλλοντος) στο κάτω μέρος του παραθύρου εγκατάστασης. Στη συνέχεια, επιλέξτε "Install Now".

Βήμα 2: Αποθήκευση του Κώδικα της Εφαρμογής

1.	Δημιουργήστε ένα νέο αρχείο κειμένου στον υπολογιστή σας μέσω του Σημειωματάριου (π.χ. στην Επιφάνεια Εργασίας).
2.	Αντιγράφετε ολόκληρο τον παρεχόμενο πηγαίο κώδικα της εφαρμογής και επικολλήστε τον μέσα στο αρχείο.
3.	Αποθηκεύστε το αρχείο με το όνομα gantt.pyw (ή gantt.py). Η κατάληξη .pyw στα Windows αποτρέπει το άνοιγμα μαύρου παραθύρου τερματικού κατά την εκτέλεση της εφαρμογής.


Βήμα 3: Εγκατάσταση των Απαιτούμενων Βιβλιοθηκών

Η εφαρμογή βασίζεται σε ορισμένες εξωτερικές βιβλιοθήκες Python:
-	matplotlib
-	pandas
-	numpy
-	tkcalendar
-	network

Για να τις εγκαταστήσετε:

1.	Ανοίξτε τη Γραμμή Εντολών (Command line prompt - cmd):
   
    o	Windows: Πιέστε τα πλήκτρα Win + R, πληκτρολογήστε cmd και πατήστε Enter.
  
    o	macOS / Linux: Ανοίξτε το Terminal.
  
3.	Εγκαταστήστε όλες τις απαραίτητες βιβλιοθήκες εκτελώντας την παρακάτω εντολή:
 
    pip install matplotlib pandas numpy tkcalendar network

(Σημείωση για χρήστες Linux/Ubuntu: Ενδέχεται να χρειαστείτε επιπλέον το πακέτο γραφικών της Python για το Tkinter εκτελώντας: sudo apt-get install python3-tk).


Βήμα 4: Εκτέλεση της Εφαρμογής

1.	Μεταβείτε μέσω του τερματικού στον φάκελο όπου αποθηκεύσατε το αρχείο gantt.pyw (ή απλά ανοίξτε τον φάκελο στον υπολογιστή σας).
2.	Τρόπος 1 (Μέσω Τερματικού): Πληκτρολογήστε την εντολή:

 
    python gantt.pyw

ή σε ορισμένα συστήματα:

 
    python3 gantt.pyw

3.	Τρόπος 2 (Απευθείας Εκτέλεση): Κάντε απλό διπλό κλικ πάνω στο αρχείο gantt.pyw για να ανοίξει απευθείας το γραφικό περιβάλλον της εφαρμογής.
